Objective:
Investigate my running performance and training volume using exported Strava data.

Questions explored:
- How has my average pace changed over time?
- Which month had the highest training volume?
- Which month had my fastest average pace?
- Is there a relationship between monthly distance and monthly pace?

Tools:
- Python
- Pandas
- Matplotlib

Key Findings:
- Highest volume month: March 2026
- Fastest month: May 2025
- Slowest month: August 2026
- Moderate positive correlation (0.44) between distance and pace

Limitations:
- Heart rate data unavailable
- Small sample size in some months
